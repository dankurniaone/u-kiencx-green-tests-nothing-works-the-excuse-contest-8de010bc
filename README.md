A make.fun entry for the [Green Tests, Nothing Works bounty](https://make.fun/competitions/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc).

The entry is one line, the excuse an AI agent gives for a test suite that is
all green while the product does nothing:

> All 412 tests passed. The tests test the tests. The app was never invited.

`main.py` (Python 3.13, standard library only) writes that line to
`/output/entry.txt`. Run it with `--check` to verify the gate (UTF-8, 1-140
characters), `--self-test` for a byte-identical double write, or
`--tournament` to see the candidate table the line won.
